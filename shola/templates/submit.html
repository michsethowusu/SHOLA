  • text — the item. Rows with the same text are the same item: it exists once however many languages answer it.
  • language — required, and a language code, even for a single language. Write all for a line that applies to every language.
  • priority — optional. 1 is finished before 2 is started, so the part that matters most gets done even if the project never finishes.
  • option1… — optional, up to five, per language. Give them where you have them; leave them out and the first speaker writes the wording, which becomes the option the next speaker sees. Both at once is fine — the translation project here has machine translations in four languages and nothing in the other eighty-four.

A header row is expected. Volunteers can always write or edit an answer, whatever the file says.

Language codes
