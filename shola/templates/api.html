Data API

Ghanaian-language data, answered by speakers. No key, no sign-up, no rate limit, CC BY 4.0.

Three lists

You wantAsk for
A dictionary
one clear answer each		 /api/items/<project>/<language>/verified
The hard cases
skipped, reported or tied		 /api/items/<project>/<language>/problem
Everything
every answer, with counts		 /api/items/<project>/<language>

?format=csv on any of them. limit and offset to page.

Example

curl "{{ config.SITE_URL }}/api/items/everyday-words/twi/verified?limit=5"

{
  "project": "everyday-words", "language": "twi", "set": "verified",
  "total": {{ counts.get('twi', 0) }},
  "items": [
    { "item": "water", "answer": "nsuo", "chose": 5, "of": 5, "from": "option" }
  ]
}

from is option if the answer came with the project, volunteer if a speaker wrote it.
