Data API

Pull Ghanaian-language data straight out of SHOLA. No key, no sign-up, no rate limit. Every answer here came from a speaker, not a machine.

Verified, or collected. An item is verified once that project's number of speakers tapped the same offered option — five for the translation project, and each project sets its own. Items where speakers disagreed are left out.

A wording a volunteer typed is never counted as agreement, however many people type the same thing: spelling, spacing and dialect differ, so there is no way to establish that two people meant the same. It is kept as a collected answer and it becomes an option for the next speaker — once they tap it, those taps count like any other, and a volunteer's own wording can end up the verified answer.

A project whose file carried no options verifies nothing at all. Its answers are all collected; ask for them with ?answers=typed, and they are never mixed into the verified set.

Examples

Fetch a page of Twi words

curl "{{ config.SITE_URL }}/api/words/twi?limit=50"

Only entries three speakers agreed on

curl "{{ config.SITE_URL }}/api/words/ewe?min_votes=3"

Straight into pandas

import pandas as pd

df = pd.read_csv("{{ config.SITE_URL }}/api/words/ga?format=csv&limit=1000")
df.head()

Page through everything

import requests

BASE = "{{ config.SITE_URL }}/api/words/dagbani"
entries, offset = [], 0
while True:
    page = requests.get(BASE, params={"limit": 1000, "offset": offset}).json()
    entries += page["entries"]
    if len(page["entries"]) < 1000:
        break
    offset += 1000

print(len(entries), "verified entries")

One entry in detail

To see every wording given for one word, including those that were not chosen: 

GET /api/entry/<id>/<language>

Returns the full tally — each wording, its vote count and its share — alongside the confirmed answer. Useful when you want all the variants rather than one.

Notes

  • Responses are UTF-8. Ghanaian orthographies use characters like ɛ ɔ ŋ ɖ ƒ ɣ ʋ ʒ, so decode as UTF-8 rather than Latin-1 or they will arrive mangled.
  • Nothing is cached. Every request reflects the answers given up to that moment, so a word can become verified between two calls.
  • The words are released under CC BY 4.0: use them for anything, including commercially, as long as you credit SHOLA and Ghana Open Data.
  • Unverified machine translations for all {{ stats_words if stats_words else '478,822' }} words are published separately in GhanaNouns. Use those when you need full coverage, and this API when you need wording a speaker stood behind.
